# SauceDemo QA Test Plan

## 1. Project Overview

This project focuses on manual testing of the SauceDemo e-commerce web application. The purpose is to verify that key user flows, including login, product selection, cart functionality, checkout and order completion, work as expected.

## 2. Testing Objectives

- Verify that users can successfully log in with valid credentials.

- Verify that invalid login attempts are handled correctly.

- Verify that products can be added to and removed from the shopping cart.

- Verify that checkout validation works correctly for required fields.

- Verify that users can successfully complete an order.

- Identify and document any defects found during testing.

## 3. Scope

- User login and authentication

- Product display and sorting

- Adding and removing products from the shopping cart

- Cart item and price verification

- Checkout form validation

- Order summary verification

- Order completion and confirmation

## Out of Scope

- Performance and load testing

- Security testing

- Backend infrastructure testing

- Payment processing with real financial information

- Cross-browser compatibility testing

## 4. Testing Types

- Functional Testing — Verify that application features work according to expected behavior.

- Negative Testing — Verify that the application handles invalid inputs and actions correctly.

- Validation Testing — Verify that required fields and input rules are enforced.

- Regression Testing — Re-test previously tested functionality after changes or fixes.

- End-to-End Testing — Verify the complete user journey from login through order completion.

## 5. Test Environment

- Application: SauceDemo

- Testing Type: Web application testing

- Browser: Google Chrome

- Operating System: Windows

- Testing Approach: Manual testing

## 6. Defect Management

- Defect title

- Steps to reproduce

- Expected result

- Actual result

- Severity

- Priority

- Status

- Evidence, such as screenshots when applicable

Defects will be reported for further investigation and resolution.

## 7. Entry and Exit Criteria

Entry Criteria

Testing can begin when:

- The SauceDemo application is accessible.

- Valid test credentials are available.

- The required test scenarios have been identified.

- The test environment is ready.

Exit Criteria

Testing can be considered complete when:

- All planned test cases have been executed.

- Test results have been documented.

- Any identified defects have been documented.

- All critical test scenarios have been executed and their results documented.

- A final test summary has been completed.
